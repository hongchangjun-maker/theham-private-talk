# 사용자 매뉴얼

## 가입과 로그인

관리자에게 받은 초대코드를 입력하고 가입 승인을 요청합니다. 승인 전에는 서비스에 입장할 수 없습니다. 비밀번호는 다른 서비스와 다르게 설정하고 MFA가 제공되면 활성화하세요.

## 채팅

- 채팅방을 선택하고 입력창에서 `Enter`로 전송합니다.
- 줄바꿈은 `Shift + Enter`입니다.
- 파일은 허용된 확장자와 용량 안에서만 업로드할 수 있습니다.
- 민감정보가 포함된 메시지나 파일은 전송 전에 조직 정책을 확인하세요.

## 영상회의

1. 회의의 `입장 준비`를 선택합니다.
2. 카메라와 마이크 권한을 허용하고 미리보기를 확인합니다.
3. 회의 서버 연결 상태와 대기실 안내를 확인합니다.
4. 화면 공유 전 다른 창이나 알림에 민감정보가 보이지 않는지 확인합니다.

권한이 거부되면 브라우저 주소 표시줄의 사이트 권한에서 카메라와 마이크를 허용한 뒤 다시 시도합니다.

## PWA 설치

Chrome·Edge는 설치 버튼 또는 주소 표시줄의 설치 아이콘을 사용합니다. iPhone Safari는 공유 메뉴에서 `홈 화면에 추가`를 선택합니다.

## 문제 해결

- `채팅 서버 설정 필요`: 운영자가 Supabase 연결을 완료해야 합니다.
- `영상 서버 설정 필요`: RealtimeKit 연결 전에는 장치 점검만 가능합니다.
- 초대 만료: 관리자에게 새 초대링크를 요청합니다.
- 메시지 전송 실패: 네트워크 복구 후 전송 여부를 확인하고 중복 전송하지 않습니다.
