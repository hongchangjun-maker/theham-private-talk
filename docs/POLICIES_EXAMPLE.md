# 개인정보처리방침 및 이용약관 예시

> 이 문서는 제품 구조를 설명하기 위한 초안입니다. 실제 사업자 정보, 처리 목적, 법적 근거, 국외 이전, 보존기간, 수탁사, 아동 이용 여부를 반영하고 배포 전 법률 전문가의 검토를 받으세요.

## 개인정보처리방침 핵심 항목

1. 처리 항목: 이메일, 표시 이름, 소속, 프로필, 접속기기, IP, 로그인 기록, 채팅·파일·회의 메타데이터
2. 처리 목적: 회원 승인, 비공개 커뮤니케이션 제공, 보안, 신고 처리, 고객지원
3. 보유기간: 계정과 콘텐츠 유형별 관리자 설정 및 법령에 따른 기간
4. 제3자/수탁사: Cloudflare 및 실제 운영에 사용하는 영상·알림·메일 제공자
5. 이용자 권리: 열람, 정정, 삭제, 처리정지, 계정 탈퇴와 문의 방법
6. 안전조치: Worker 권한검사, 전송구간 암호화, 감사 로그, 비밀 관리, 백업
7. 회의 녹화: 기본 비활성, 활성화 시 목적·보존기간·동의 철회 방법

## 이용약관 핵심 항목

1. 초대와 관리자 승인을 받은 사용자만 이용할 수 있습니다.
2. 계정 공유, 무단 접근, 악성 파일, 타인의 권리 침해, 불법 콘텐츠를 금지합니다.
3. 관리자는 보안과 운영을 위해 계정 또는 방을 제한할 수 있으며 중요한 조치에는 기록을 남깁니다.
4. 서비스 장애, 예정 점검, 데이터 내보내기와 계약 종료 절차를 명시합니다.
5. 각 사용자는 채팅·회의에서 공유하는 정보에 필요한 권한을 보유해야 합니다.
